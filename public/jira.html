❓ How to Use

1

Generate API Token

Go to your Atlassian account settings and create an API token for authentication.

2

Configure Connection

Enter your JIRA URL, email, and API token. Test the connection to verify credentials.

3

Select Project

Load your JIRA projects and select the one you want to import stories from.

4

Import Stories

Click Import to fetch stories. Stories without points will be auto-estimated using AI.

5

Use Imported Data

Export to JSON or send directly to the Planning Board for sprint planning.

🔒

Security Note

Your JIRA credentials are stored locally in your browser and never sent to our servers. All JIRA API calls are made directly from your browser to JIRA's servers.
